# PortSwigger & PentesterLab: Web Security Journey

This repository contains my comprehensive notes on PortSwigger Web Security Academy. I have also completed all PentesterLab exercises, but I’ve kept my solutions private in accordance with their policies.

Working through both platforms has helped me develop strong skills in web application and API penetration testing, as well as source code review. These hands-on exercises have strengthened my understanding of common vulnerabilities, exploitation techniques, and practical approaches to identifying and assessing security flaws.
